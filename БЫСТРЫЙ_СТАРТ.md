# ⚡ Быстрый старт - Деплой на Bothost

## 📦 Что нужно сделать

### 1. Подготовить файлы

```bash
cd "c:\Users\User\Desktop\TG bot"

# Инициализировать Git
git init

# Добавить все файлы
git add .
git commit -m "Подготовка к деплою"
```

### 2. Создать репозиторий на GitHub

1. Зайти на https://github.com/new
2. Название: `tg-bot-shop`
3. Создать репозиторий
4. Скопировать URL (например: `https://github.com/username/tg-bot-shop.git`)

### 3. Отправить код в GitHub

```bash
git remote add origin https://github.com/ВАШ_USERNAME/tg-bot-shop.git
git push -u origin main
```

### 4. Настроить Bothost

1. Войти в панель Bothost
2. Создать новый проект
3. Выбрать "Подключить GitHub"
4. Выбрать репозиторий: `tg-bot-shop`
5. Добавить переменные окружения:
   ```
   BOT_TOKEN=ваш_токен_бота
   OWNER_ID=439446887
   ```
6. Главный файл: `bot_test.py`
7. Нажать "Deploy"

### 5. Проверить работу

1. Открыть Telegram
2. Найти бота
3. Нажать `/start`

## ⚠️ Важно про базу данных

### SQLite на Bothost:

**Плюсы:**
- ✅ Простота (файл shop.db)
- ✅ Не нужно внешних сервисов

**Минусы:**
- ❌ Может сбрасываться при деплое
- ❌ Не работает на read-only хостингах

### Если SQLite не работает:

**Используйте PostgreSQL:**

1. Зарегистрироваться на https://elephantsql.com/
2. Создать базу (бесплатно)
3. Скопировать URL подключения
4. На Bothost добавить переменную:
   ```
   DATABASE_URL=postgresql://...
   ```
5. В `database.py` заменить SQLite на PostgreSQL

## 🆘 Если что-то не так

**Бот не запускается:**
- Проверьте логи в панели Bothost
- Убедитесь, что BOT_TOKEN правильный

**Данные теряются:**
- Используйте PostgreSQL вместо SQLite
- Или храните данные в JSON

**Ошибка "database is locked":**
- SQLite не работает на хостинге
- Переключитесь на PostgreSQL
