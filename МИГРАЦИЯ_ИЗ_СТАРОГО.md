# 🔄 Миграция из старого бота в новый

## 📋 Что делает миграция

Переносит ВСЕ данные из старого бота в новый с SQLite базой:
- ✅ Товары (обычные и индивидуальные)
- ✅ Заказы со всеми элементами
- ✅ Клиентов и админов
- ✅ Подписки на уведомления о появлении товара
- ✅ Отзывы
- ✅ Статистику пользователей

---

## 🚀 Пошаговая инструкция

### Шаг 1: Подготовка

**Найдите файл со данными старого бота:**
```
shop_data.json  # Файл из старого бота
```

**Скопируйте его в папку нового бота:**
```
c:\Users\User\Desktop\TG bot\shop_data.json
```

---

### Шаг 2: Запуск миграции

```bash
cd "c:\Users\User\Desktop\TG bot"
python migrate_from_old_bot.py
```

**Что произойдет:**
1. Создастся новая база данных `shop.db`
2. Все данные из `shop_data.json` перенесутся в базу
3. Создается бэкап старых данных

---

### Шаг 3: Проверка

После миграции вы увидите отчет:

### Шаг 4: Запуск нового бота

```bash

```

**Проверьте:**
- [ ] Все товары на месте
- [ ] Все заказы видны в админке
- [ ] Клиенты отображаются

---

### Шаг 5: Остановка старого бота

После проверки можно остановить старого бота на Bothost и запустить нового.

## 🔧 Настройки для Bothost

### 1. Обновите файлы на Bothost:

```bash
git add .
git commit -m "Миграция на SQLite с сохранением данных"
git push
```

### 2. Bothost автоматически:
- Скачает новые файлы
- Установит зависимости
- Запустит бота

### 3. База данных:
- **Важно:** Bothost может сбрасывать `shop.db` при деплое
- **Решение:** Используйте внешнюю БД (PostgreSQL) или храните данные в JSON

## ⚠️ Важные моменты

### 1. Бэкап старых данных

Перед миграцией **обязательно** сделайте копию `shop_data.json`:
```bash
copy shop_data.json shop_data_backup_manual.json
```

### 2. Проверка данных

После миграции проверьте:
- Количество товаров: `SELECT COUNT(*) FROM products;`
- Количество заказов: `SELECT COUNT(*) FROM orders;`
- Количество пользователей: `SELECT COUNT(*) FROM users;`

### 3. Если что-то пошло не так

**Удалите базу и запустите миграцию заново:**
```bash
del shop.db
python migrate_from_old_bot.py
```

## 🆘 Решение проблем

### Ошибка: "shop_data.json не найден"

**Решение:**
1. Найдите файл старого бота
2. Скопируйте в папку: `c:\Users\User\Desktop\TG bot\shop_data.json`

### Ошибка: "database is locked"

**Решение:**
1. Закройте все подключения к базе
2. Удалите `shop.db`
3. Запустите миграцию заново

### Товары не отображаются

**Проверьте:**
```bash
python -c "from database import get_all_products; print(len(get_all_products()))"
```

Должно показать количество товаров.
