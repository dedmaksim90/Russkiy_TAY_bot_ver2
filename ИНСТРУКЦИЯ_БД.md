## 📈 Примеры SQL-запросов

### Выручка за месяц
```sql
SELECT SUM(total_amount) as revenue
FROM orders
WHERE status != 'cancelled'
AND created_at >= datetime('now', '-30 days')
```

### Топ товаров
```sql
SELECT p.name, SUM(oi.quantity) as sold
FROM order_items oi
JOIN products p ON oi.product_id = p.id
GROUP BY p.id
ORDER BY sold DESC
LIMIT 10
```

### Активные клиенты
```sql
SELECT u.first_name, COUNT(o.id) as orders
FROM users u
JOIN orders o ON u.user_id = o.user_id
GROUP BY u.user_id
ORDER BY orders DESC
```

## 🆘 Решение проблем

### Ошибка "database is locked"
Убедитесь, что все подключения закрыты. Используйте контекстный менеджер:
```python
with get_db_connection() as conn:
    # работа с БД
```

### Бот не видит данные
Проверьте загрузку:
```python
from database import get_all_products
products = get_all_products()
print(f"Товаров в БД: {len(products)}")
```

### Ошибка миграции
Проверьте наличие JSON:
```bash
dir shop_data.json
```
